# The Beauty Space

Лабораторна робота: веб-застосунок каталогу косметики.

## Реалізовані пункти:
- **C1 (MVC):** Реляційні сутності categories, products, reviews, повний CRUD та зв'язки.
- **C2 (Cloud):** Розгортання веб-сервісу та бази даних PostgreSQL на платформі Render.
- **C3 (CI/CD):** Автоматичний пайплайн розгортання в GitHub Actions при оновленні гілки main.
- **C4 (Docker):** Контейнеризація застосунку за допомогою Dockerfile та оркестрація в Docker Compose.
