# The Beauty Space

Лабораторна робота: веб-застосунок каталогу косметики.

## Реалізовані пункти:

### Архітектура, хмара та розгортання
* **C1 (MVC)**: Реляційні сутності categories, products, reviews, повний CRUD та зв'язки.
* **C2 (Cloud)**: Розгортання веб-сервісу та бази даних PostgreSQL на платформі Render.
* **C3 (CI/CD)**: Автоматичний пайплайн розгортання в GitHub Actions при оновленні гілки main.
* **C4 (Docker)**: Контейнеризація застосунку за допомогою Dockerfile та оркестрація в Docker Compose.
* **C5**: Безпека та оптимізація запитів до бази даних, параметризовані SQL-запити.
* **C6**: Документування та стандартизація REST API ендпоінтів.
* **C7**: Централізована обробка помилок (Error Handling Middleware) та логування запитів.
* **C8**: Пагінація, сортування та багаторівнева фільтрація каталогу товарів.

### Інтерфейс користувача та фронтенд-можливості
* **B2**: Валідація даних форм на клієнті й сервері, санітизація вхідних параметрів.
* **F1**: Адаптивний та доступний дизайн (Mobile-first, семантична розмітка).
* **F2**: Динамічний пошук та асинхронне оновлення контенту без перезавантаження сторінки (AJAX/Fetch).
* **F3**: Анімації інтерфейсу та плавні мікровзаємодії на базі CSS.
* **F6**: Графіка та 2D-мінігра на чистому HTML5 JavaScript Canvas (`/game`).

### Мережева взаємодія та реальний час
* **C10**: Моніторинг мережевого стану (Connectivity Panel) — відображення онлайн/офлайн статусу та стану з'єднання з базою (`/connectivity`).
* **C12**: Інтерактивний редактор нотаток (Notes Editor) із автозбереженням (`/editor`).
* **C13**: Синхронізація редактора нотаток у реальному часі через WebSockets.
* **C14**: Підсвічування активності, руху курсорів та присутності інших користувачів наживо.
* **C16**: Автентифікація через сторонній сервіс (Google OAuth 2.0).
* **C18**: Спільна інтерактивна дошка (Shared dashboard / space) для кількох користувачів із синхронізацією малювання через WebSockets (`/shared-space`).

### ШІ та інтеграції
* **C21**: ШІ-агент у вигляді чату зі стрімінгом через Server-Sent Events (SSE), відображенням думок (thoughts) та викликом інструментів (tool calling) (`/ai-consultant`).
* **C22**: MCP сервер (Model Context Protocol) з набором інструментів для читання та запису даних каталогу товарів і замовлень.
