# The Beauty Space

Лабораторна робота: веб-застосунок каталогу косметики.

##  Гід зі швидкого запуску (Quick Start)

### 1. Запуск через Docker Compose (рекомендовано)
Для запуску бази даних PostgreSQL та сервера застосунку в ізольованому середовищі:
\`\`\`bash
docker compose up --build -d
\`\`\`
Застосунок буде доступний за адресою: [http://localhost:3000](http://localhost:3000)

### 2. Запуск тестів
Усі вимоги лабораторної роботи покриті автоматизованими модульними тестами (`node:test`):
\`\`\`bash
node --test
\`\`\`


## Реалізовані пункти:
- **C1 (MVC):** Реляційні сутності categories, products, reviews, повний CRUD та зв'язки.
- **C2 (Cloud):** Розгортання веб-сервісу та бази даних PostgreSQL на платформі Render.
- **C3 (CI/CD):** Автоматичний пайплайн розгортання в GitHub Actions при оновленні гілки main.
- **C4 (Docker):** Контейнеризація застосунку за допомогою Dockerfile та оркестрація в Docker Compose.
- **C5 (REST API)**:Повноцінний CRUD інтерфейс без класичних View (`GET`, `POST`, `PUT`, `DELETE`).Робота з чистим JSON, валідація статусів `200`, `201`, `400`, `404`.
- **C6 (Bootstrap Landing Page)**:Інтерактивна посадкова сторінка товару (`/products/:id`) на заміну стандартного Details.Постійно зафіксована контактна планка (`sticky-contact-bar`) при скролі.Адаптивна мобільна сітка та швидке замовлення.
- **C7 (SEO-оптимізація та Schema.org)**:Налаштування мета-тегів, Open Graph, Twitter Cards, семантичних `<h1>` та Favicon.Впровадження мікророзмітки `Schema.org` (Product, Offer, AggregateRating) у форматі JSON-LD.
- **C8 (Інтеграція з OpenStreetMap / Leaflet)**:Відображення фізичних точок присутності на мапі України (`/stores`).Одночасний рендеринг множини локацій та динамічна клієнтська фільтрація за товарами.
- **F1 (Візуалізація статистики (Chart.js))**:Побудова інтерактивних графіків (стовпчиковий розподіл залишків та кругова діаграма категорій).Серверна агрегація даних через PostgreSQL `GROUP BY`.
- **F2 (Autocomplete Selector (Select2 + AJAX))**:Заміна статичного `<select>` на динамічний Autocomplete у формі редагування (`/products/:id/edit`).AJAX-завантаження з бекенду (`/api/categories/search`), debounce-затримка 300 мс, пошук від 3 символів.
